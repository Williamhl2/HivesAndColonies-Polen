# Polen Memory

Polen's memory system should support more than survival.

It needs to cover two layers at once:

- practical world memory
- narrative memory recovery

## Practical memory

This is the memory Polen uses for day-to-day autonomy.

Examples:

- Residence
- Shelter
- Danger
- Light
- Flowers
- Bees
- Source

These memories help with:

- survival
- comfort
- navigation
- routines
- calming behavior

## Narrative memory

This is the memory layer tied to identity and story recovery.

Examples of future or partial targets:

- symbols she half-recognizes
- names like Befsh, Cosmic, Luna, Noia, Noris, Jeff, and Vanilla
- healer training
- war fragments from Hive
- grief triggers
- legendary or queen-facing revelations

## Design rule

Not every remembered thing should become explicit dialogue immediately.

A memory may first appear as:

- hesitation
- mood shift
- attraction to a place or object
- discomfort
- an unfinished line
- a fully surfaced story event

## Current implementation note

The current playable build is still much stronger on practical memory than on full narrative memory recovery.

That is acceptable for now, but docs and future features should treat narrative memory as first-class scope.
